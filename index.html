Selected Work

Projects Built for Real Problems

Nutq (نُطق)

AI / Speech iOS + Android On-Device AI

An Arabic and English transcription app that turns audio, video, YouTube links and text into a transcript, then writes a summary with key takeaways. Both AI models run on the phone: no server, no cloud API, so recordings stay private and the app works offline.

Key challenges solved:

  • Fine-tuned Gemma 3 1B for Arabic summarization, quantized to 4-bit and run on the phone with LiteRT-LM.
  • Built an on-device speech pipeline: FFmpeg audio extraction into Moonshine ASR, with a live transcript.
  • Cut the install size to ~96 MB by downloading the models on demand, with resume and SHA-256 checks.
  • Kept long jobs running in the background with Swift and Kotlin platform channels and progress notifications.
